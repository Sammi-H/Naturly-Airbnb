Airbnb School Project – Fullstack Next.js App
This project is a fullstack Airbnb-style application built with Next.js, MongoDB, modular components, and secure user authentication. Users can browse listings, view details, select dates, manage guests including pets, filter pet-friendly listings, calculate prices, and book both stays and Experiences. The app uses Next.js App Router, React, Next.js API Routes, the native MongoDB driver, the Context API for global state management, and is styled with vanilla CSS and CSS Modules. Authentication is implemented with bcrypt for password hashing together with middleware for protected routes, and all server logic is handled through API routes.
The application supports full user signup and login, secure password handling, session-based protection, and clean separation between UI, logic, and data. It follows a modular component structure with global state handled via Context, and all interactions with the database are done through the native MongoDB driver inside Next.js API routes.
To run the project locally, install dependencies and start the development server using:

npm run dev.
